# misago-pyjobs-aggregator-plugin



![Test workflow](https://github.com/raydeal/misago-pyjobs-aggregator-plugin/actions/workflows/tests.yml/badge.svg)
[![Test Coverage](https://coveralls.io/repos/github/raydeal/misago-pyjobs-aggregator-plugin/badge.svg?branch=main)](https://coveralls.io/github/raydeal/misago-pyjobs-aggregator-plugin?branch=main) ![Works on Python 3.12](https://img.shields.io/badge/python-3.12-blue.svg)


Misago plugin used to collect job adverts and publish them on the
https://python-forum.pl forum.

Version 0.1.x imports recent matching offers from [solid.jobs](https://solid.jobs) and publishes them as Misago threads, with updates added as new posts in the existing thread.

See [the architecture and operations guide](docs/architecture.md).
